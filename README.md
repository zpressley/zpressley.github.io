# Portfolio

A lightweight static portfolio site. No framework, no build step, no dependencies —
plain HTML, one stylesheet, and about 100 lines of JavaScript. Open `index.html` in a
browser and it works.

**Live:** https://zpressley.github.io/

## Adding a project

1. Copy `projects/_template.html` to `projects/your-slug.html` and write it up.
2. Copy one `<a class="card">` block inside `#project-grid` in `index.html`, point it
   at the new page, and edit the title, blurb, and `<span class="tag">` values.

The cards are plain HTML rather than generated by JavaScript, so Google and
LinkedIn link previews can actually read them. The filter chips and the project
count build themselves from the tags on the cards — nothing else to update.

3. Commit and push. GitHub Pages redeploys in about a minute.

## Layout

```
index.html              home — hero, work grid, about, contact
projects/
  _template.html        copy this for each new case study
  clay-enrichment-waterfall.html
  signal-engine.html
  pantheon-leagues.html
decks/
  signal-not-noise.html self-contained slide deck, served as its own page
assets/
  css/style.css         all styling; colors are CSS variables at the top
  js/main.js            theme toggle + project filtering (reads the cards in the DOM)
  img/                  screenshots, and og-image.png for link previews
  files/                resume PDF and other downloads
.nojekyll               tells GitHub Pages to serve the files as-is
```

## Changing the look

Every color lives in the `:root` block at the top of `assets/css/style.css`.
`--accent` is the teal; change that one value and the whole site follows.
The light theme overrides sit right below it.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Hosting a standalone deck or document

Drop a self-contained HTML file in `decks/` and it's served at
`https://zpressley.github.io/decks/your-file.html` — no config needed. To show it
inside a case study, embed it:

```html
<div class="embed">
  <iframe src="../decks/your-file.html" title="Deck title" loading="lazy"></iframe>
</div>
```

PDFs go in `assets/files/` and link the same way.

## Link previews

`assets/img/og-image.png` is what unfurls when the site is shared. It's 1200×630 and
referenced by absolute URL in the `og:image` tag in `index.html` — relative paths don't
work for social crawlers. Regenerate it if the headline changes.
