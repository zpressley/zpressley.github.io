What this sample is and isn't

The real tool runs two engines: fuzzy string matching, and a local sentence embedding model that picks up what the string match misses. Only the first can run in a browser — a language model won't fit in a static page. So this sample is the string half.

That turns out to be the useful thing to show. Watch what the string matcher does with BNSF Railway, which belongs to Berkshire Hathaway. It has no idea, and it says so by scoring low. Cases like that are exactly why the second engine exists.

How the scoring works

Names are normalized first — lowercased, punctuation stripped, and legal suffixes like Inc, Corp, LLC, and Holdings removed, so Acme, Inc. and Acme Inc stop being different strings. Then two similarity measures run and the higher one wins: an edit-distance ratio over alphabetically sorted tokens, which handles reordering and small typos, and a token overlap ratio, which handles one name being a subset of another.

If a domain is supplied it's scored separately and blended in, weighted at a quarter of the total — a matching domain is strong evidence, but not on its own conclusive when the names disagree. Results band at 90 and 75: safe to use, worth a spot check, send to a human.
